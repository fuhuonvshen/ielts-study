# IELTS Listening Practice

一个本地优先的雅思听力词汇练习工具。所有数据存储在浏览器 IndexedDB 中，无需注册，无需联网，打开即用。

**[开始练习](https://fuhuonvshen.github.io/ielts-study/)**

## 为什么做这个项目

背单词软件很多，但大多数要么是"看英文选中文"的视觉记忆，要么是脱离语境的死记硬背。这个工具的核心理念是：**用耳朵学单词**——每个练习都从"听"开始，在真实语境中建立单词的语音和含义连接。

## 练习模式

| 模式 | 流程 | 考察能力 |
|------|------|----------|
| **听音选义** | 听单词发音 → 从四个中文释义中选出正确项 | 听力理解 |
| **看词选义** | 看英文单词 → 从四个中文释义中选出正确项 | 词义识别 |
| **听音拼写** | 听单词发音 → 拼写出完整英文单词 | 拼写能力 |
| **看义选词** | 看中文释义 → 从四个英文单词中选出正确项 | 反向记忆 |

每轮 10 个单词，支持键盘快捷键（1-4 选选项，Tab 重听，← 回顾上一题，→/Enter 下一题）。

## 每日训练（实战演练）

每天自动从 CGTN、ECNS 等英文新闻源抓取 5 篇最新文章，通过 DeepSeek 大模型：

1. 按雅思难度选取 15~30 个单词挖空
2. 逐段翻译成中文
3. 浏览器语音合成朗读全文

边听边填词，点击"查看翻译"可对照中文，提交后展示成绩和逐空回顾。

> 每天早上 8:00（北京时间）通过 GitHub Actions 自动更新，无需手动操作。

## 主要功能

- **单词库** — 浏览、搜索近万雅思词汇，查看释义、音标、例句、同义词、短语
- **错词本** — 自动收录练习出错的单词，支持一键专项练习
- **收藏夹** — 标签分类管理重点词汇
- **学习统计** — 每日练习次数和正确率趋势图
- **AI 单词分析** — 5 种分析风格（学术/幽默/暗黑/故事/记忆术），从记忆技巧、近义词辨析、用法提示、趣味知识四个维度解读单词
- **AI 发音教练** — 逐音素拆解单词发音，教你口型和舌位，不透露拼写
- **变速播放** — 0.75x / 1x / 1.25x / 1.5x / 2x 五档语速
- **重复朗读** — x1 / x5 / x10 三档循环播放
- **英音发音** — 默认英式发音，练习页多国浏览器语音可选
- **自适应布局** — 可调节左右分栏比例和字体缩放
- **数据管理** — 支持 JSON 导入导出、一键重置

## 技术栈

React 18 · TypeScript · Vite 5 · Tailwind CSS 3 · Zustand · Dexie.js (IndexedDB) · React Router v6 · DeepSeek API · GitHub Actions

## 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

如需使用 AI 功能，在项目根目录创建 `.env` 文件：

```env
VITE_ANTHROPIC_API_KEY=你的DeepSeek_API_Key
```

每日训练的爬虫脚本位于 `scripts/daily-crawl/`，可手动运行：

```bash
pip install -r scripts/daily-crawl/requirements.txt
python scripts/daily-crawl/daily_crawl.py
```
